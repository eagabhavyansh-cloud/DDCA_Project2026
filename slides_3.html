A combinational-logic system that reads a 4-bit binary value and displays its decimal — and, above 9, hexadecimal — equivalent on a digit display, designed and verified in Logisim.

01Problem Statement

What the system needs to do

The core design problem this project solves.

Design and implement a 4-bit binary-to-decimal conversion and display system using digital logic gates.

  1. 01Accept a 4-bit binary input.
  2. 02Process the input using combinational logic.
  3. 03Convert the binary input into its corresponding decimal representation.
  4. 04Display the result on a digit display.
  5. 05Correctly handle all 16 possible 4-bit input combinations.

05Design & Methodology

How the circuit was built, step by step

The exact procedure followed in Logisim.

Components used
×4Input PinWiring
×1SplitterWiring
×1Hex Digit DisplayInput / Output
Only 3 components total — the Hex Digit Display does all the decoding work internally.
Procedure
1Open Logisim, create a new circuit.
2Place 4 Input Pins vertically: A (MSB) at top, D (LSB) at bottom.
3Add a Splitter; set Fan Out = 4, Bit Width In = 4.
4Wire all 4 Input Pins to the Splitter's inputs.
5Place a Hex Digit Display.
6Wire the Splitter's output to the display.
7Save the circuit.
8Use the Poke Tool to toggle each pin 0 / 1.
9Observe: 0000–1001 → 0–9, 1010–1111 → A–F.
06Logic Gate Design

The logic inside the display

What the Hex Digit Display is doing on our behalf.

Segment a
a = A + C + BD + B′D′
Segment b
b = B′ + C′D′ + CD
Segments c–g
derived the same way, per segment

A digit display lights segments a–g based on A, B, C, D. Each segment is a Boolean function, found via a truth table and minimised with a K-map.

Our Hex Digit Display performs exactly this internally — extended to A–F — so we use it directly instead of ~20 hand-wired gates.
